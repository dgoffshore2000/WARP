# 关于

**WARP**（Wave-structure Analysis Response Program）是基于开源 BEM 求解器 [Nemoh](https://lheea.ec-nantes.fr/valorisation/logiciels-et-brevets/nemoh-presentation)（École Centrale Nantes / LHEEA）的波浪-结构相互作用前后处理工具。

- 仓库：<https://github.com/dgoffshore2000/WARP>
- 问题反馈：请通过 GitHub Issues 提交，附上模型参数与运行日志
- 许可：GPL-3.0（与所捆绑的 Nemoh 内核一致，见仓库 [LICENSE](https://github.com/dgoffshore2000/WARP/blob/main/LICENSE)）

Web 界面基于 [NiceGUI](https://nicegui.io/) 构建。

V2.0 为 Web 版首个公开发布版本（完整重写，替代桌面版 V1.0）。
