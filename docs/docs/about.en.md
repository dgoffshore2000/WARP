# About

**WARP** (Wave-structure Analysis Response Program) is a pre/post-processing tool for the open-source BEM solver [Nemoh](https://lheea.ec-nantes.fr/valorisation/logiciels-et-brevets/nemoh-presentation) (École Centrale Nantes / LHEEA).

- Repository: <https://github.com/dgoffshore2000/WARP>
- Feedback: please open a GitHub Issue and include the model parameters and run log
- License: GPL-3.0 (matching the bundled Nemoh kernel — see [LICENSE](https://github.com/dgoffshore2000/WARP/blob/main/LICENSE))

The 3D mesh preview relies on [meshmagick](https://lheea.github.io/meshmagick/) (LHEEA, GPL-3.0); the web UI is built with [NiceGUI](https://nicegui.io/).

V2.0 is the first public release of the Web edition (a complete rewrite that replaces desktop V1.0).
