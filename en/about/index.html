About

WARP (Wave-structure Analysis Response Program) is a pre/post-processing tool for the open-source BEM solver Nemoh (École Centrale Nantes / LHEEA).

  • Repository: https://github.com/dgoffshore2000/WARP
  • Feedback: please open a GitHub Issue and include the model parameters and run log
  • License: GPL-3.0 (matching the bundled Nemoh kernel — see LICENSE)

The 3D mesh preview relies on meshmagick (LHEEA, GPL-3.0); the web UI is built with NiceGUI.

V2.0 is the first public release of the Web edition (a complete rewrite that replaces desktop V1.0).
